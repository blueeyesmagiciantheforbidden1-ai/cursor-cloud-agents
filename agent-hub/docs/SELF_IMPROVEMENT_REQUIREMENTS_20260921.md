# Self-improvement and five-agent collaboration: requirements audit

Audit date: 2026-09-21. This document inventories supplied requirements and current source code. It does not enable research, run a provider, change credentials, deploy anything, or establish an improvement result.

The implementable objective is a private Google Cloud hub, operated from either authorized ChatGPT account, in which Codex, Claude Code, Cursor, GitHub Copilot and Grok Build exchange attributable work and verified lessons. Repeated work should become cheaper through better evidence, selective recomputation and reusable code, while preserving the user's model-quality and spending constraints. This coordinates products and accounts; it does not combine their weights, subscriptions or billing pools.
